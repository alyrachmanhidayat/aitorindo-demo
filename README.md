# Aitorindo Jaya Perkasa — Dashboard Konveksi (Demo)

Prototipe tampilan untuk demo ke klien. Seluruh data adalah contoh (dummy) dan tersimpan di memori browser —
data kembali ke awal setiap kali halaman di-refresh. Tidak ada backend.

Isi: Dashboard, Purchase Order, Papan Produksi, 8 halaman tahap produksi
(Order Kain → Datang Bahan → Marker → Antri Cutting → Antri Sablon → Sewing → Finishing → Pengiriman),
Stok (barang jadi & sisa kain), Invoice, Piutang, Laporan.

## Menjalankan

```bash
npm install
npm run dev      # http://localhost:3000
npm run build    # cek build & type
```
